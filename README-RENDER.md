# 🚀 نشر «المسار العالمي اللوجستي» على Render — نسخة مجانية بدون بطاقة

هذا المستودع جاهز: لا تحتاج تثبيت أي برنامج ولا كتابة أي أمر.
اتّبع الدليل المصوّر: **النشر-الدائم-Render.html** (في نفس حزمة المشروع) — أو اقرأ الملخص هنا.

---

## ١) ارفع هذا المجلد إلى GitHub

1. أنشئ مستودعًا جديدًا باسم `masar-api` (اختر **Public**).
2. من صفحة المستودع: **Add file → Upload files**.
3. **مهم:** افتح هذا المجلد، حدّد كل ما داخله (Ctrl+A)، واسحبها إلى صفحة GitHub.
   يجب أن يكون `render.yaml` و `package.json` و `server/` و `app/` في **أعلى المستودع مباشرة**.
4. اضغط **Commit changes**.

## ٢) شغّله على Render

1. [render.com](https://render.com) ← **Get Started** ← تسجيل بحساب GitHub.
2. **New + → Blueprint** ← اختر مستودع `masar-api` ← **Connect**.
3. Render يقرأ `render.yaml` تلقائيًا. سيطلب قيمة **ADMIN_PASSWORD**
   ← اكتب كلمة مرور قوية لحساب `admin` **واحفظها في مكان آمن**.
4. **Apply** ← انتظر حتى تصبح الحالة **Live** (٣–٦ دقائق).

## ٣) تأكّد

افتح: `https://<رابط-خدمتك>.onrender.com/health`

يجب أن ترى:

```json
{"ok":true,"status":"ok","version":"1.0.0-phase5", ... "counts":{"users":1,"shipments":37}}
```

## ٤) اربط التطبيق

في التطبيق: زر **⚙** أعلى يسار الشاشة ← الصق الرابط ← **«فحص الرابط»** ← **«حفظ ومتابعة»** ←
سجّل الدخول: `admin` + كلمة المرور التي وضعتها في الخطوة ٢.

## ملاحظات صادقة عن الخطة المجانية

| البند | الخطة المجانية | الخطة المدفوعة (Starter 7$/شهر) |
|---|---|---|
| الرابط الثابت | ✅ | ✅ |
| قرص دائم للبيانات | ❌ البيانات تُفقد عند كل **إعادة نشر** | ✅ لا تُفقد |
| النوم بعد خمول | ١٥ دقيقة (استيقاظ ٣٠–٦٠ ثانية) | لا ينام |
| بطاقة بنكية | لا تُطلب | مطلوبة |

- **النسخ الاحتياطي إلزامي على المجاني:** التطبيق ← الإعدادات (ضغط مطوّل) ← «🛡️ الإدارة والإشعارات» ←
  «فتح لوحة الإدارة» ← تبويب **الإشعارات** ← **⬇️ نسخة احتياطية**.
- للترقية لاحقًا: استبدل محتوى `render.yaml` بمحتوى `render-paid.yaml` ثم Commit — Render يعيد النشر وحده.

## متغيّرات البيئة

| المفتاح | مطلوب | المعنى |
|---|---|---|
| `ADMIN_PASSWORD` | ✅ | كلمة مرور المدير العام (تُنشأ مرة واحدة عند أول تشغيل) |
| `DATA_DIR` | مضبوط مسبقًا | مجلد البيانات (`/opt/render/project/src/data`) |
| `STORAGE_PERSISTENT` | مضبوط مسبقًا | `false` على المجاني، `true` مع القرص الدائم |
| `SEED_DEMO` | مضبوط مسبقًا | `1` = استيراد ٣٧ شحنة و٦ مزادات تجريبية أول مرة |
| `CORS_ORIGINS` | مضبوط مسبقًا | `*` (اسمح للتطبيق بالاتصال) |
| `PUBLIC_URL` | اختياري | رابط خدمتك — يُستخدم في روابط الإشعارات |
| `FCM_SERVICE_ACCOUNT` / `APNS_*` | اختياري | للإشعارات الأصلية على الجوال |

## ملفات مهمة

- `render.yaml` — إعدادات النشر المجاني (Render يقرأه تلقائيًا).
- `render-paid.yaml` — نسخة الخطة المدفوعة مع القرص الدائم.
- `Dockerfile` — بديل إن أردت النشر على أي منصة تدعم Docker.
- `server/server.js` — الخادم (Node 20، بلا أي حزم خارجية).
